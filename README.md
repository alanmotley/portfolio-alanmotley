# Alan Motley — Creative Portfolio

Personal portfolio for Alan Motley, a producer, filmmaker, journalist, interviewer, photographer, and digital experience designer.

The site brings together documentary and location-based filmmaking, public-engagement work, photography, enterprise production leadership, and digital storytelling.

## Featured work

- **Microsoft Surface production studio** — creative leadership, production-environment design, technical integration, operational planning, and enterprise storytelling infrastructure.
- **Seattle Locks** — location-based documentary filmmaking filmed and edited with a Sony FX3 camera, including visual composition and original voiceover narration.
- **Beneath the Surface** — Microsoft Surface production leadership and studio development. The portfolio distinguishes program management and production leadership from filming and editing responsibilities.
- **Aerial cinematography** — selected drone projects, kept separate from traditional cinematography and documentary work.
- **Photography** — city, event, concert, and place-based image collections from Seattle, Los Angeles, Vancouver, Brooklyn, Manhattan, Mexico, Barcelona, Venice Beach, and Burning Man.

## Project structure

This is a lightweight static site built with HTML, CSS, JavaScript, and locally hosted media assets. The `dist/` directory mirrors the local preview output used during development.

## Local preview

Open `index.html` directly in a browser or serve the repository root with any simple static web server.
